# CSDS 335 Data Mining Project 1

The purpose of this project is to create and evaluate several classification models for two datasets, including Nearest Neighbor, Decision Trees, Naive Bayes, Support Vector Machines, AdaBoost, and a neural network. The a 10 fold cross validation is used to evaluate results as well based on accuracy, recall, precision, and F1. Please see my submission for a full report. 

The following are included:
- project_1.ipynb
This is a Jupyter Notebook file containing all preprocessing, model training, experimentation, and evaluation
- project1_dataset1.txt
Original dataset 1.
- project1_dataset2.txt
Original dataset 2.
- data_1_normalized.csv
Normalized dataset 1, generated and saved in notebook.
- data_2_normalized.csv
Normalized dataset 2, generated and saved in notebook.

The following libraries are required:
- pandas
- NumPy
- scikit-learn
- PyTorch
- Matplotlib
- Seaborn

Other notes:
- Make sure project_1.ipynb, project1_dataset1.txt, and project1_dataset2.txt are in the same directory.
- You can run all cells in order without the csv dataset files, or you can run just the model training/evaluation cells in order with the csv's.
- These datasets were provided and general project instructions were provided by Dr. Jing Ma.
